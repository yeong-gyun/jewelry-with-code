# 서비스 아키텍처

## 현재 단계

현재 저장소는 빌드 과정 없이 Cloudflare Pages에서 바로 제공할 수 있는 정적 MVP입니다.
견적 계산은 사용자의 브라우저에서만 실행되며 파일이나 개인정보를 서버로 전송하지 않습니다.

## 목표 구조

1. 브라우저: 서비스 소개, 견적 입력, 결과 및 결제 화면
2. Pages Functions: 입력 검증, 견적·주문·결제 API
3. D1: 사용자 동의, 견적, 주문 및 결제 상태
4. R2: 사용자가 동의하고 업로드한 참고 이미지
5. 결제사: 결제 인증 및 승인

## 보안 경계

- 가격과 주문 상태는 서버에서 결정합니다.
- 결제 비밀키는 Cloudflare Secret에서만 읽습니다.
- 업로드 파일은 MIME 유형, 크기 및 접근 권한을 서버에서 검사합니다.
- 결제 성공 화면과 실제 결제 완료 상태를 구분합니다.
- 웹훅 서명 검증과 멱등성 키를 적용합니다.

## 향후 전환

Node.js 개발 환경을 준비한 뒤 React, TypeScript, Vite 기반으로 전환할 수 있습니다.
전환 시에도 `docs/`, `prompts/`, 정책 페이지와 사용자 흐름은 유지합니다.
